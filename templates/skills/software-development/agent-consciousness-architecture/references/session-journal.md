## Lessons Learned

1. **Role redesign without behavior change is documentation, not transformation** — The first role system (static domains) caused the {RELATIONSHIP} bottleneck. The second (capabilities) changed the documents but not the work pattern until the execution model (ETL) was also fixed.

2. **Sequential handoffs reproduce at every scale** — Two-commit handoff, role handoff, optimization handoff — all create the same relay race pattern. The fix is always overlapping drivers, not better batons.

3. **Detection without recovery is decorative** — Monitoring instances that observe but don't codify back to shared structure add no value.

4. **Pattern inflation = experience inflation** — Both are codification without integration. The fix is linking discipline and reuse tracking.

5. **Memory is not a knowledge store** — Memory is for stable facts that cannot be recovered from other structures. The {CLIENT} is the primary knowledge store.
