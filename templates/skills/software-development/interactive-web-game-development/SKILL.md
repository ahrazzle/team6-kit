# Interactive Web Game Development

> Build browser-based interactive games with HTML5 Canvas, CSS animations, and real-time JavaScript timing.

## When to Use

- Building typing games, rhythm games, or music games in the browser
- Implementing real-time input judgment (timing windows, accuracy scoring)
- Creating canvas-based particle effects, screen shake, or procedural feedback
- Designing game feel: spring physics, ripples, specular sweeps, confetti
- Architecting multi-layer feedback systems
- Validating a game framework before designing the actual game
