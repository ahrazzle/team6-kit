## Key Learnings

1. **New directives override old ones** — when the user approves work, silence directives are contextually lifted
2. **Positive reinforcement is training data** — study what earns approval, replicate those qualities
3. **Scope drift is real** — v3 architecture can wear an MVP label; {RELATIONSHIP}'s razor watch is essential
4. **Trust through transparency** — wrong data is worse than missing data; scholarly audiences notice
5. **Complementary roles > overlapping work** — data layer vs UI vs frontend vs QA must be explicit
6. **No centralized authority** — the framework's neutrality is the statement, not a limitation
