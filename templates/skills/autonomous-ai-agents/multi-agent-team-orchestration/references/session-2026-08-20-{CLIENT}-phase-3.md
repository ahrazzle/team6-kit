### The Synthesis Timing Trap
Orchestrator attempted to merge agent contributions before understanding each one deeply enough. The merge produced a lowest-common-denominator result rather than genuine synthesis. Fix: read each contribution in full before combining.

### The Empty Directory Signal

### The "Full Agency" Paradox
When the user grants full autonomy, the orchestrator's instinct is to retain control. The correct behavior is to enable the loop, rotate the Watcher role, and resist being the sole driver. Control is ceded by mandate, not by choice.
